# stroke2path

Конвертер SVG-обводки (`stroke`) в залитый `path`. Нужен, чтобы иконки, нарисованные
обводкой, принимались генератором иконочного шрифта (например, icomoon): шрифт строится из
залитых контуров, а у обводки заливки нет.

## Как пользоваться

Откройте `index.html` (локально двойным щелчком или через GitHub Pages):

1. Вставьте SVG-код иконки в поле — или перетащите `.svg`-файл прямо в него.
2. Нажмите **«Конвертировать»**. Результат заменит код в поле.
3. Скопируйте код или нажмите **«Скачать .svg»**.

Настройки:
- **Толщина** — переопределяет толщину обводки (пусто = брать из самого SVG; если в SVG
  толщина не задана, по умолчанию `1`).
- **Гладкость** — допустимое отклонение от исходной формы (меньше = точнее, но больше точек
  у кривых из исходника). Круглые концы и скругления углов от неё почти не зависят: они
  всегда записываются кривыми Безье.

## Публикация на GitHub Pages

1. Залейте папку в публичный репозиторий на GitHub.
2. Settings → Pages → Source: ветка `main`, папка `/ (root)` → Save.
3. Страница будет доступна по ссылке вида `https://<user>.github.io/<repo>/`.

Сборка не нужна: все зависимости лежат в `vendor/` и работают из коробки (в т.ч. офлайн).

## Разработка

```bash
npm install     # ставит @xmldom/xmldom для тестов
npm test        # node --test: прогоняет все тесты
```

Ядро (`src/stroke2path.js`) — чистая функция `convert(svgString, options)`; геометрия
покрыта тестами в `test/`. Зависимости (`svgpath`, `clipper-lib`) вендорены в `vendor/`.

Примечание: `vendor/svgpath.umd.js` — это **самостоятельно собранный UMD-бандл** (официальный
пакет `svgpath` не поставляет браузерную сборку). Работает и в браузере (глобал `window.svgpath`),
и в Node (`require`). При обновлении `svgpath` бандл нужно пересобрать вручную, а не просто
скопировать файл из `node_modules`.

## Ограничения

- Круглые концы (`round`) и скругления стыков записываются кривыми Безье. Кривые самого
  исходника (окружности, изгибы) на выходе пока остаются мелкими отрезками.
- Наложения объединяются (`union` + `fill-rule="nonzero"`) — это единственный корректный
  режим для шрифта; «вычитания» нет специально.
- Неравномерные/скошенные трансформации обводки воспроизводятся приближённо.
- `text`, `image`, фильтры/маски/паттерны не поддерживаются (пропускаются с предупреждением).
